# A real G1

In the humanoid challenge the robot belongs to the runner: it owns the G1 and the safety filter, and asks
a policy server for joint targets 30 times a second. Kaiku can be that server, with the operator in the
gloves where the policy would be.

## 1. Kaiku, with the lead robot served

```bash
python -m kaiku.app.run --gloves 127.0.0.1 --record demos --g1 8000
```

## 2. The challenge's runner

On the robot's computer, where the challenge's repository is:

```bash
python -m aaltonomous.deploy.runner --backend real --policy ws://KAIKU_MACHINE:8000 --team kaiku --time-limit 120
```

Over wifi, put the relay next to the runner instead. The runner sends its camera images with every request
(3 MB), and the relay keeps those on that machine and fetches only the 28 numbers from Kaiku. It is one
file and needs numpy, msgpack and websockets, all of which the runner has:

```bash
scp kaiku/app/g1.py ROBOT_PC:
python g1.py --lead ws://KAIKU_MACHINE:8000        # on the robot's computer; serves ws://127.0.0.1:8000
python -m aaltonomous.deploy.runner --backend real --team kaiku --time-limit 120
```

## What the robot does

- It starts from where it stands and moves to the lead robot's pose at no more than 0.97 of the filter's
  speed limits (arms 1 rad/s, hands 3 rad/s). Start it with the hands above the table.
- Every step goes through the challenge's own safety filter before it is sent, so the runner's filter has
  nothing to clip. If the operator reaches where the robot may not go, the robot stops at the edge.
- When Kaiku says nothing for half a second (between scenes, or a lost connection) the robot holds.
- The 47 echoes keep working in their own scenes. The real robot moves as the lead robot does.

## Checked without the robot

The runner has a mock robot. With it, the runner followed Kaiku's lead for 60 seconds: 1,800 ticks through
the official safety filter, 29.6 commands a second (the challenge asks for 27), none clipped.

```bash
python -m kaiku.app.run --n 4 --g1 8000 &
python -m aaltonomous.deploy.runner --backend mock --policy ws://127.0.0.1:8000 --team kaiku --time-limit 60
python -m aaltonomous.deploy.replay --synthetic 300 --policy ws://127.0.0.1:8000     # the challenge's rate check
```

`tests/test_g1.py` runs the same against the runner's code, including a lead that swings its arms through
the table.
