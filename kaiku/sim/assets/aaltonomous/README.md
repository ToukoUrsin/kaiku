Scene definition, joint spec and printed-part meshes of the Junction 2026 Aaltonomous humanoid
challenge, copied from https://github.com/zupermiez/aaltonomous-humanoid (MIT, see LICENSE). The STL files are re-saved as binary STL (MuJoCo does not read ASCII STL); geometry is unchanged.
Kaiku builds its MuJoCo twin from these files so that demonstrations recorded here are valid for
that challenge's task, action space and scoring rule.
